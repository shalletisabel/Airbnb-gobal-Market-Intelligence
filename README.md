## Airbnb Global Market Intelligence & Business Performance Analytics

## Project Overview
This project aims to develop a data-driven business intelligence solution to analyse Airbnb's global property listings, host performance, pricing patterns and guest experiences across multiple international cities.

The objective is to transform raw data into meaningful business insights and support management decision-making.

## Business Objectives
- Analyse property distribution across international markets.
- Identify pricing patterns across cities and property types.
- Evaluate host performance and listing quality.
- Analyse guest ratings and review activity.
- Identify market-level business opportunities.
- Develop interactive management dashboards.

## Dataset
The project uses four source files:
- Listings.csv
- Reviews.csv
- Listings_data_dictionary.csv
- Reviews_data_dictionary.csv

## Technology Stack
- Microsoft Excel – Data cleaning and MIS reporting
- SQL – Data extraction and business analysis
- Power BI – Interactive dashboards and KPI monitoring
- Tableau – Optional business visualisation
